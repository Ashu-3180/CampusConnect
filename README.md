# CampusConnect 🎓

A full-stack student community platform designed to help university students connect, collaborate, discover opportunities, and participate in campus events.

## Features

- Student authentication
- Community posts
- Collaboration opportunities
- Skill-based student discovery
- Campus events
- Student profiles

## Tech Stack

### Frontend
- React
- Vite

### Backend
- Node.js
- Express.js

### Database
- MongoDB
