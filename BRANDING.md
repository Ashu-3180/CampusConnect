# CampusConnect — Final Transparent SVG Brand Kit

Uses the final approved one-by-one CampusConnect logo artwork. No design was altered; opaque background areas were removed for transparent use.

Design: two thick rounded interlocking C forms around a cyan connection diamond; left C deep navy; right C blue-to-cyan; CampusConnect wordmark; CONNECT • COLLABORATE • CREATE tagline.

Palette: #0A2540, #2563EB, #06B6D4.

SVG assets preserve the finalized artwork inside a transparent SVG canvas to avoid changing the approved geometry/typography through re-tracing.
